# Last Light: тема для Steam

Неофициальная тема для клиента Steam в духе тихих сюрреалистичных пиксельных игр вроде OneShot: чёрный фон, фиолетовые рамки-схемы, золотая лампа с оранжевым свечением, неоновый город за библиотекой и лампочка на заставке. Вся графика и текст свои, материалов из игр в теме нет, с разработчиками OneShot тема не связана.

Работает через загрузчик [Millennium](https://steambrew.app/).

## Установка

1. Скачай `Install-LastLight.bat`.
2. Запусти его двойным кликом.

Если Windows покажет предупреждение SmartScreen, нажми «Подробнее» → «Выполнить в любом случае».

Установщик находит Steam, при необходимости скачивает официальный установщик Millennium и проверяет его подпись (в окне Millennium нужно будет нажать установку), закрывает Steam, копирует тему, включает её и запускает Steam снова. Запущенную игру он не трогает: попросит сначала её закрыть.

## Настройки

В настройках темы в Millennium можно выбрать цветовую схему (фиолетовая ночь, розовый город, изумрудная, глубокий синий) и отключить заставку, HUD и сканлайны. После смены схемы перезапусти Steam.

## Своя картинка

В настройках темы в Millennium есть опция Character: путник, своя картинка (My image) или без персонажа (None). Для своего варианта положи PNG с прозрачным фоном сюда и перезапусти Steam:

```text
<папка Steam>\millennium\themes\LastLight\assets\character.png
```

В комплект темы картинка не входит. Используй свой арт или изображение, на которое у тебя есть права. Переустановка темы удаляет этот файл, поэтому храни копию.

## Удаление

Запусти `Uninstall-LastLight.bat`. Он удалит тему и вернёт стандартный вид. Сам Millennium останется.

## Что нужно знать

- Millennium и такие темы Valve официально не поддерживает.
- После обновлений Steam часть стилей может слетать, особенно в магазине.

## Разработка

Стили лежат в `theme/`, скрипты установщика в `installer/`. После правок пересобери `.bat`:

```bash
powershell -ExecutionPolicy Bypass -File build.ps1
```
